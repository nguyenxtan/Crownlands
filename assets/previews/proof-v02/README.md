Terminology: Hộ trận (Ward) is a finite combat shield from the Radiant path, protecting same-owner units in one row. Seal/ấn is a path emblem or ability motif, not beginner protection. Beginner guard is a separate scenario rule delaying selected NPC offensives; it is not an invulnerability bubble. No gameplay rules are changed in this art revision.
